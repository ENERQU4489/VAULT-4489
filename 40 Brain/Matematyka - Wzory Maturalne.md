## 1. Wartość bezwzględna liczby
Definicja:
$$|x| = \begin{cases} x & \text{dla } x \ge 0 \\ -x & \text{dla } x < 0 \end{cases}$$

## 2. Potęgi i pierwiastki
Dla $a \neq 0$: $a^{-n} = \frac{1}{a^n}$ oraz $a^0 = 1$.
Dla $a \ge 0$: $a^{\frac{m}{n}} = \sqrt[n]{a^m}$.

## 3. Logarytmy
Definicja:
$\log_a b = c \iff a^c = b$
Wzory:
- $\log_a(x \cdot y) = \log_a x + \log_a y$
- $\log_a \frac{x}{y} = \log_a x - \log_a y$
- $\log_a x^r = r \cdot \log_a x$

## 7. Funkcja kwadratowa
Postać ogólna: $f(x) = ax^2 + bx + c, a \neq 0$
Wyróżnik (Delta):
$$\Delta = b^2 - 4ac$$
Miejsca zerowe:
- $x_1 = \frac{-b - \sqrt{\Delta}}{2a}$, $x_2 = \frac{-b + \sqrt{\Delta}}{2a}$ (dla $\Delta > 0$)
